Wav2Lip in your browser

Lip-sync a face to any speech. Face detection, the model and video encoding all run on this device with LiteRT.js, so your files never leave it.

Settings

If the lips look smeared or doubled, lower the padding. If the mouth jitters, raise the smoothing.

Make the model with python scripts/convert.py --checkpoint wav2lip_gan.pth --batch 1. Use the fp32 file on WebGPU; int8w is smaller but no faster. Batch 8 gives more throughput.

Built from wav2lip-tflite: LiteRT.js for Wav2Lip, MediaPipe BlazeFace for faces, Mediabunny for MP4.
